# UI 结构与页面归属（信息架构）

> 这份不写像素，只写**谁指向谁、怎么回去、一页放什么**。
> 动手之前先在这里落三行（入口 / 返回 / 子页），比事后补入口便宜得多——
> 2026-10-23 就踩过一次：功能写完了、代码也在跑，用户说"没看到"。

## 0. 三条硬规矩

1. **一页一件事。** 设置是"分组索引"，不是"所有开关的列表"。一页上堆了四类东西，
   用户就要在滚动里找，而且找不到的时候不知道是自己没滚到、还是根本没有。
2. **不给假开关、不给假表单。** 没接核心的项：灰行 + "待接 Px"。接了一半的项：
   能点的部分照常，不能点的部分写明差什么。**点了没反应比没有这个开关更坏。**
3. **每一页都写三行**：谁指向它 / 它怎么回去 / 它下面的子页怎么办。
   返回只在顶层注册一次，按**栈深**判断（D118），子页不各写一套。

## 0.5 参考对象：像的是布局与交互，不是像素

用户 2026-10-23 明确：**UI 布局和这些交互要和 kelivo / RikkaHub 很相似**——那是成熟的人类交互美学样本，
不是我们自己发明一套。像的是层级、间距节奏、行高、手势与返回习惯；不像的是像素与代码
（kelivo 是 AGPL，D15：一行代码都不能抄，只参考移动端的结构与行为）。

做每个页面前先对一遍这张表，对不上的地方要么改，要么写清为什么不一样：

| 场景 | 对齐点 |
|---|---|
| 设置 | 分组小标题 + 圆角卡片包行；行内左图标、右 chevron 或当前值；子页一项一张卡 |
| 列表 | 行高 56–64dp；分隔用间距而不是横线；右侧时间、预览单行省略 |
| 抽屉 | 从左滑出、遮罩 0.60；**展开时清焦点并收键盘**；自上而下：用户块（头像/名字/问候语）→ 搜索框（两态，右滑切换；尾巴朝左）→ 新对话+会话列表 → 助手坞（头像=助手设置、名字=**自绘面板**、齿轮=设置），见 D139 / D141 |
| 输入岛 | 多行输入 + **底部一行图标按钮**：左 模型/搜索/思考/工具，右 ＋菜单/语音/发送-停止（同一按钮换形态）；长按发送出「仅保存为助手/用户消息」（D138） |
| 消息 | 用户右（气泡 + 名字 + 时间 + 头像 + 动作行）、**助手左且没有气泡**（头像 + 名字 + 时间 + Markdown 正文）；动作行：复制/重新生成/编辑/更多；**长按 = 选择消息**；思考块折叠；工具调用折叠卡；压缩分界线 |
| 面板 | 底部上滑、点遮罩关闭、动画未落位不可点（D109） |
| 返回 | 左上角箭头，语义与系统返回一致，按栈深处理（D118） |
| 图标按钮 | 热区 48dp、视觉 22dp、`contentDescription` 必填（D103） |

## 1. 现在实际长什么样

```
聊天页（首页，D125）              ← 启动直接进来，是一个还没落库的空白会话
```

## 2. 设置：从"六节平铺"改成"分组索引 + 子页"

目标形状（照 kelivo 的结构，不照像素）：**分组小标题 + 圆角卡片包住行 + 行内左图标右 chevron/当前值**。
索引页上**不摆开关**，只摆入口和"当前值摘要"；开关进各自的子页。

| 分组 | 子页 | 状态 |
|---|---|---|
| 外观 | 启动器图标（已实现）、**主题三态（已实现）**；**背景（纯色/图片/视频，按助手）** 下一步；自定义主题只有灰行+预览位 | 一半（见 `docs/ui/appearance.md`） |
| 会话与上下文 | 压缩建议线 / 绝对线、视觉覆盖、上下文窗口默认值 | 灰行（待接 P4 / P3.3） |
| 模型与提示词 | 七条压缩提示词（只读页能进）；模型列表与供应商是灰行 | 一半 |

| 调试 | **日志（三种通道，已实现）**、原生层状态、版本（构建号灰行） | 已实现 |
| 关于 | **开源许可（已实现）**：本项目 GPL 全文、第三方声明、`LICENSES/` 三份全文，读的是包里真实的 `assets/notices/`；构建号灰行 | 一半 |

索引页每一行的右侧写**当前值**，不写"去设置"——用户不该为了知道现在是几秒而点进去。

## 3. 日志：三种通道，四个按钮，一个齿轮

形状（用户 2026-10-23 定）：

```
设置 → 调试 → 日志                        ← 索引页
  ├─ 上下文日志      12.4 KB / 8 MB   ●开  ›
  ├─ 请求日志        0 B    / 8 MB   ●开   ›
  ├─ 调试日志        84.1 KB / 8 MB  ●开  ›
  └─ 右上角 ⚙ → 日志设置页：三种各自的开关 + 上限档位（2/4/8/16/32 MB）
       点进任意一行 → 该通道子页：查看 / 复制 / 导出 / 清除 + 预览区（自己滚）
```

**为什么分三种**，不是加个"详细模式"：

| 通道 | 写什么 | 现在有没有生产者 | 默认 |
|---|---|---|---|
| 上下文 `context` | 组装过程：注入了哪些块、各来源 token、压缩轮次与前后对比、分界线位置 | **没有**（等 P4 真正接上压缩线） | 开，8 MB |
| 请求 `request` | HTTP：URL、状态码、耗时、重试次数、SSE 事件计数；header **脱敏**，body 只在"详细"开关下写 | **没有**（HTTP 层还没过 FFI 面） | 开，8 MB；body 关 |
| 调试 `debug` | 应用事件：启动、库、图标切换、原生层、崩溃前状态 | 有（现在 `NLog` 的调用点） | 开，8 MB |

三条理由：

- **量的差别**：一次请求能写几十行（重试、SSE 分片），混进调试日志会把"启动那五行"冲掉，
  而启动的那几行恰恰是排查时最常要的。
- **隐私的差别**：请求日志里有 header 和可能的 body，**默认必须脱敏**（密钥只留末尾 4 位，D28）；
  调试日志里不该出现这些东西，就不该共用同一个脱敏开关。
- **清理的差别**：清请求日志（常常是用来释放空间、或者清掉敏感内容）时，不该把调试日志一起清掉。

**没有生产者时界面要直说**："这一类还没有产生者（等 P7 HTTP 层）。"
给个空列表装正常，等于让用户以为"日志功能坏了"。

实现约定（改代码时照这个来）：

- 三个文件：`files/logs/{context,request,debug}.log`，各自轮转、各自上限、各自清理。
- 开关与上限存 `SharedPreferences`（`app_log`）：必须在第一行日志之前读到，
  settings 表要开库、要线程，够不上（D117 的同一个理由）。
- 四件事各自独立：查看只读尾部、复制进剪贴板、导出走 SAF、清除要二次确认。

## 4. 聊天页

三层：顶栏 / 消息区 / 输入岛。2026-10-24 按 D125 + D126 改过一轮，改的是**操作习惯**，不是装饰：

- **没有返回箭头**：它是根页面。左上角是抽屉（≡，Lucide `panel-left`），右上角是「新建会话」。
  "退回去"这个动作在这里不存在——它上面没有页面。
- **空白会话不落库**：`sessionId == null` 时界面给静态提示；第一次存消息才建会话，
  路由原地换成带 id 的同一条（栈深不变），所以不闪、不跳页。
- **用户消息**：右侧。**名字在上排、时间在下排，两行都在头像左侧**（整块右对齐、头像贴右），
  下面气泡（`primaryContainer`、圆角 16、按内容收放、最多 78% 屏宽），气泡下一排动作：
  复制 / 刷新 / 文字转语音 / 翻译 / 更多（后三个灰着，D133）。
- **助手消息**：头像 + 名字/时间占一行，**正文在下面整行铺开**，左边缘与头像左边缘同一条线；
  左右边距都是 **18dp**、头像 32dp（D139 / D141 / D142）。
- **时间**：`yyyy-MM-dd HH:mm:ss`（系统 12 小时制时 `hh:mm:ss a`），库里是毫秒（D132）。
- **「更多」七项**（顺序固定）：编辑 / 增强编辑 / 分享 / 选择消息 / 创建分支 / 删除此版本 / 删除所有版本
  （最后一项只在有其他版本时出现，D133）。
- **分享**：选择条上的「分享」或「更多 → 分享」→ 底部面板**两排**：上排 `思考调用` / `详细信息`，
  下排 `MD`（真做，系统分享）/ `图片`（灰，待接），见 D134。
- **消息版本**（`<` `n/n` `>`，三色：白=未编辑 / 蓝=显示原文 / 红=显示编辑后）：**设计已定、未实现**，见 D135。
- **助手消息**：左侧、**没有气泡**。头像 28dp + 名字 + 时间，正文直接铺在背景上，走
  `MarkdownBody`（标题/列表/代码块/引用/分隔线/粗斜体/行内代码/链接文字，见 D131）。
  思考块、工具卡、断块仍是卡片，左侧留 38dp 缩进对齐正文。
- 间距：同角色 4dp、异角色 12dp；时间 `yyyy-MM-dd HH:mm:ss`，`createdAt == 0` 不显示。
- **长按 = 进入选择模式**（D130）：顶部换成选择条（取消 / 已选 N / 复制 / 删除（灰）），
  点别的消息加选；选择模式下藏起输入区，返回键先退选择。复制**不在**长按里，在动作行与「更多」里。
- **输入岛**：整条圆角 24；**输入框下面一行图标按钮**——左：模型 / 搜索 / 思考 / 工具，右：＋菜单 / 语音 / 发送-停止
  （↑ 与方块换形态）。六个能力都没接，点一下会在提示行说明"待接什么"；**长按发送键**出
  「仅保存为助手消息 / 仅保存为用户消息」（这两项今天就能用，走 `append_text`，D138）。再下面一行说明现在到底做了什么——
  `nmoi_turn_run_json` 还没接，↑ 只是把话存进库里，长按 ↑ 存为助手消息（验气泡形状用，
  接上模型就删）。**不写"发送"然后不发送。**

「上下文窗口」面板以后从顶栏进，面板自己的返回先关面板再退页面。
