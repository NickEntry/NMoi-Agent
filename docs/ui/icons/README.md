# 图标规范（P6.5）

聊天界面里**按钮不写字，只显示图标**（2026-10-22 定）。这份文件管图标本身怎么画、
怎么用、从哪儿来；图标包、导入导出与匹配规则见 [`../icon-packs.md`](../icon-packs.md)，
来源与商标约定见 [`NOTICE.md`](NOTICE.md)。

| 目录 | 内容 | 来源 |
|---|---|---|
| `actions/` | 界面动作图标 **31** 个 | [Lucide](https://lucide.dev) `lucide-static@1.61.0`，ISC（其中 11 个源自 Feather，MIT） |
| `providers/` | **供应商**图标 **21** 个 | [Lobe Icons](https://github.com/lobehub/lobe-icons) `@lobehub/icons-static-svg@1.97.0`，MIT（彩色） |
| `models/` | **模型**图标 **16** 个 | 同上（彩色） |
| `thinking-*.svg`（本级） | 思考强度七档 | 自绘（D69），"仪表盘"语法 |

`actions/divider.svg` 也是自绘：Lucide 没有能读成"分界线"又不跟折叠箭头撞的形状。

**供应商与模型是两套图标，不合并**：`providers/zhipu` 是"智谱 AI 这家公司"，
`models/glmv` 是"GLM-V 这个模型"。同一个会话头上两个位置可能各显示一个。

## 1. 画法（只对 `actions/` 与自绘图形）

- 画布 **24×24**，`viewBox="0 0 24 24"`，图形留在 3–21 的可用区里（描边算进去）。
- 描边 **1.75**，`stroke-linecap="round"`、`stroke-linejoin="round"`、`fill="none"`。
  2 太粗、1.5 在 22px 下发灰；1.75 是这两档之间的折中。
- 颜色一律 `currentColor`。**不要给动作图标写死颜色**——颜色来自主题的
  `onSurface` / `onSurfaceVariant`，只有需要强调时才用 accent。
- `providers/` `models/` 是纯填充的彩色标，**不参与**上面这条：品牌色是识别的一部分，不改。

## 2. 用法

| 场景 | 视觉尺寸 | 热区 |
|---|---|---|
| 输入岛、顶栏主操作 | 22 | ≥ 48dp |
| 列表行、次要操作 | 20 | ≥ 44dp |
| chip 内部（如思考强度，D69） | 18 | 整 chip |
| 会话头/模型行的供应商+模型图标 | 40 | 整行 |

- **热区不能等于视觉尺寸**。图标不配文字之后，"点得中"全靠热区撑着：
  Android 48dp、桌面 44px，靠热区区分而不是靠留白。
- 每个图标按钮必须有 `contentDescription`（TalkBack / 读屏）和长按提示。
  没有文字的界面，读屏用户只能靠这个；少写一个，那个按钮对他就是空的。
- 禁用态用**不透明度 38%**，不换"禁用图标"，也不加斜杠。
- 加载不清空图标：原位换成旋转指示，尺寸与图标同框，避免跳位。

**三个例外，仍要文字**（和"按钮只显示图标"不冲突，是它的前提）：

1. 空状态与首次引导的说明文字。
2. 收不回来的操作：删除会话、清空历史的确认框里，按钮写"删除"而不是垃圾桶。
3. 设置里开关类项目的标题本来就是文字，图标只是前缀。

## 4. 模型与供应商图标怎么选

取图顺序（五级）、正则规则、自建图标、图标包切换，全部写在
[`../icon-packs.md`](../icon-packs.md) §3–§4。这里只记渲染侧的退化底线：

- 品牌图标解不出来（文件坏、包不匹配）→ **当没有**，走下一级，**不显示裂图占位**。
- 最终兜底是首字母方块：去掉 `[分组]` 前缀 → 取最后一个 `/` 之后 → 取第一个字母或数字；
  拉丁转大写、**CJK 原样**（"豆包-seed" 显示"豆"，不转拼音）；
  底色 `hue = FNV-1a(名) mod 24 × 15°`、`s = 0.30`、`l = 0.36`，白字；
  边长 `S` 的方块、圆角 `0.30S`、字号 `0.55S`（40dp → 圆角 12、字号 22）。
  24 档逐档看过，深色底上白字全部可读；固定八色表相邻两项容易撞色，所以不维护色表。

## 6. 加一个新图标

1. 动作图标先查 Lucide；品牌图标按 slug 查 Lobe（`providers/` 用公司名，`models/` 用模型家族名）。
2. 动作图标取来后：`stroke-width` 改 1.75、去掉 `class`、保留文件头的 license 注释。
   品牌图标：有 `-color` 用彩色，没有就用单色，**不要自己调色**。
3. 跑预览，看 **22px 与 18px** 还认不认得出；品牌图标两个主题都看一遍
   （彩色标多半是按浅色底设计的）：
   ```
   python3 scripts/icon_preview.py docs/ui/icons/actions /tmp/a.png --icon 22
   python3 scripts/icon_preview.py docs/ui/icons/providers /tmp/p.png --theme light
   ```
4. 改 `docs/ui/icons/NOTICE.md` 的两张表 + 根 `THIRD-PARTY-NOTICES.md` 的数量；
   更新语义映射表——映射表里没有的图标，UI 里不该出现。
