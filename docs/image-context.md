# 图片上下文（设计稿，2026-11-04）

> 用户 2026-11-04 给了别的客户端的截图：上下文窗口面板里有一行
> 「图片上下文 · 查看和管理本轮使用的图片」，点进去是这一轮用到的图。
> 这一份是**设计**，不是实现记录；已经落地的那一小块（「查看图像」只读弹窗）记在 D247。

## 1. 现在有什么

- 附件落在 `files/sessions/<会话>/images/<附件 id>.<ext>`，库里 `attachments` 表一行一条
  （`id / message_id / mime / bytes / created_at`）。
- 发请求时 `session.rs::attach_images` 按**这一轮历史里的消息 id** 去库里取图，塞进
  `ChatRequest.images`。也就是说：**谁在历史里，谁的图就进上下文**。
- 界面上：气泡里两张缩略图 + （D247 起）一块「查看图像」只读弹窗。
- 存储页（D216）按会话列出所有附件，能删文件——那是"清盘"，不是"管理上下文"。

## 2. 要解决的问题

三件事现在都做不到：

1. **看不见**：这一轮到底有几张图进了上下文、每张多大、占多少 token。
2. **拿不掉**：某张图糊了、发错了、或者就是不想让它再进下一轮，没有入口。
3. **说不清**：删掉一张图之后，那条消息在界面上会变成什么样——现在删附件等于连缩略图一起没了。

## 3. 设计

### 3.1 一句话

**上下文里的图 = 历史消息身上的附件**。管理就是"让某个附件从这一轮起不再进请求"，
而不是"把文件删了"。所以需要的是一列开关，不是一次删除。

### 3.2 数据

`attachments` 加一列 `in_context INTEGER NOT NULL DEFAULT 1`（schema v14）。

- `1`：跟着消息进请求（默认，老数据全是 1）。
- `0`：**还在库里、还在界面上**，只是不进请求。`attach_images` 只取 `in_context = 1`。

为什么不直接删：用户要的是"这张别再发出去"，不是"这张从聊天记录里消失"。
删了之后气泡里那张图会变成一个读不出来的框——那是丢东西，不是管理。

### 3.3 入口与页面

**入口一：上下文窗口面板**（`contextPercent` 那一格点开的面板）加一行，
形状照用户给的截图：

```
图片上下文        3 张 · 2.4 MB   ›
查看和管理本轮使用的图片
```

**入口二：**「查看图像」弹窗（D247）里每张图右侧一个开关「进上下文」。
两个入口打开的是**同一份数据**（`attachments.in_context`），不是两套说法。

页面（整页，不是弹窗——它是配置类的东西，关掉之后不该有"我刚才只是试了一下"的感觉）：

```
图片上下文
本轮 3 张 · 2.4 MB · 约 1.9k tokens

[缩略图] 1024 × 2048 · 812 KB     [进上下文 ●]
         sessions/<会话>/images/<id>.jpg
[缩略图] 921 × 2048 · 760 KB      [进上下文 ●]
...
这一页改的是"下一轮发不发它"，历史消息里那张图不会消失。
```

- 每张一行：缩略图 56、尺寸与大小、等宽路径、右侧行内 chip（「进上下文」/「不进上下文」）。
- 关掉之后**不删文件**，也不改消息；只是下一轮 `attach_images` 跳过它。
- 顶部一行汇总：`本轮 N 张 · 总大小 · 估算 tokens`（图按面积估，见 `tokens` 模块的
  图像口径；没有口径就先只报张数与大小，不编 token 数）。
- 空态：「这一轮没有图片」+ 一句「在聊天页「＋ → 图片」发一张」。

### 3.4 边界

- **不搬文件**：`in_context` 只是开关，路径不变（D216 的路径已经写进库、写进存储页）。
- **不改消息**：关掉之后那条消息仍然显示原图；它只是不再进请求。
- **删文件仍然在存储页**：那是另一件事（清盘），两处文案要分开写清。
- 关掉的那张要不要在气泡上标一下？**要**：缩略图角上一个「不进上下文」的小字，
  否则用户会以为它还在发——那就是"看着在用、其实没发"。

## 4. 分批

| 批次 | 内容 | 依赖 |
|---|---|---|
| ① | schema v14 + `in_context` 列 + `attach_images` 过滤 + `list_attachments` 带这一列 | 无 |
| ② | 「查看图像」弹窗里每张一个开关（写 ① 的列） | ① |
| ③ | 上下文面板那行入口 + 整页列表（缩略图 / 尺寸 / 路径 / 开关 / 汇总） | ① |
| ④ | 气泡缩略图上的「不进上下文」角标 | ① |

①②先做：它们能立刻回答"这张还发不发"，而且不动布局。
③④跟着上下文面板那一轮一起做。
