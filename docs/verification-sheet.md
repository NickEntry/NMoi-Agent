   没有"聊天模型"。**判据**：前三张「未启用」+ 左侧重置；后三张「使用当前对话模型」+ 无按钮。（V100）

## C. 聊天主流程（一条会话里连着做）

18. 发一句话。**判据**：先出现"发送中"，落库后换成那条用户消息（不是等整轮结束才出现）。（V51 / V61）
19. 让它答一段长文。**判据**：逐字长；表情符号不吞字；正文不在过程卡里。（V61 / V80 / V81）
20. 再发一句，趁生成中点停止。**判据**：先问「留着这一版 / 回到上一版」，默认留着；停止键立刻变灰。（V83 / V84）
21. 点一条**不是最新**的旧消息上的重试。**判据**：正文出现在**那一条**的位置，后面的消息不动；
    设置里改成「删掉后面的」时先弹一句"会没掉几条"。（V96 / V79）
22. 工具跑起来的时候点开那条调用。**判据**：小窗里能看到实时输出（`echo 1;sleep 5;echo 2` 分两次出现）；
    跑完自己换成结果，不写着"正在运行"。（V66 / V80 / V81）
23. 同一条消息里让它并行调两个读工具。**判据**：两条各占一行、同时跑。（V74）
24. 发三张图（其中一张 20 MB）。**判据**：大图被跳过、其余照常，回话写"有 1 张没读出来"；正文三段转录。（V99 / V102 / V63）
25. 默认模型里把「视觉覆盖」指到一个多模态模型，再发一张带文字的截图（不打字）。
    **判据**：先"正在读 1 张图…"，随后那条用户消息正文是转录文字。（V102）
26. 把视觉覆盖改成未启用，再发一张。**判据**：这次发原图（正文是"（图片）"）。（V102）
27. 输入框上方「图片上下文 N/M」：点开、丢掉一张、再让它「查看图像」。**判据**：计数对得上；
    当轮就能看到新加的那张（不是下一轮）。（V68 / V85 / V88）
28. 长按侧边栏一条会话 → 详细信息。**判据**：六行都能长按复制；数字与聊天页数得出来的一致；
    删掉会话后那几行写「…」不写 0。（V103）
