# notes —— 给 AI / 开发者看的

设计思路、决策记录、验证清单、踩过的坑、计划，都放这里。**用户不看这些**。

两条约定：

- **面向用户的写在 `docs/`**，用户手册以那边为准。
- **两边都有用的**：正文只写一份、放 `docs/`，这里留一句指向它（`见 docs/xxx.md`）。
  反过来复制一段过来，等于两份迟早对不上。

- `decisions.md`：D 编号，为什么这么选、否掉了什么。
- `PLAN.md`：0.1x 那些行，做到哪、没做什么。
- `verification.md`：真机清单（V 编号）。
- `lorebook.md` / `voice.md` / `message-parts.md` …：分主题的设计稿。
- `archive/`：按 200 KB 切的旧文，编号不重排。
