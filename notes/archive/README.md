# 归档目录（切分规则）

> 用户 2026-11-04 定：**已经验证过的、或者太长的历史，切出去归档**，正文只留还在用的那一段。
> 每个归档文件大约 **100 KB**；正文一旦过了 **200 KB**（或者一眼看得出"它会一直长下去"），
> 就按这一份的规矩切一次。

## 1. 什么时候切

满足任意一条就切：

- 文件 ≥ **200 KB**；
- 或者它**会一直往下追加**（决策、真机清单、踩坑记录这类），总量迟早过线。

## 2. 怎么切

- 按**编号边界**切（`## D…` / `### V…` / `## 2026-…`），不按行数硬切——
  切在一条记录的中间，读的人要先拼一次才看得懂。
- 每份**约 100 KB**（90–110 都算合理）。
- 归档文件叫 `<原名>_old<N>.md`，从 1 开始，放这个目录。
- 正文顶部留一行指针：「更早的 X 在 `docs/archive/<file>_old1.md`」，
  并写清归档覆盖的编号范围。
- **编号不变**：D 编号、V 编号全仓库唯一，切出去之后引用照样指得到。
  这也是为什么不重新编号——重编号等于把全仓库的引用一起改一遍。

   一半在旧文件、一半在新文件的中间态不该留在工作树里过夜。
