## 3. 数据

`assistants` 现在是库里的表还是设置 JSON？现读 `AssistantRepository`——这一页的字段
（temperature / maxTokens / thinking / subAgent）都在 `AssistantEntry` 里，
新增字段**跟着它走**，不要为「头像/背景」另开一张表：

- `top_p REAL NULL`
- `context_messages INTEGER NOT NULL DEFAULT 0`
- `default_workspace INTEGER NOT NULL DEFAULT 0`
- `use_avatar INTEGER NOT NULL DEFAULT 1`
- `use_name INTEGER NOT NULL DEFAULT 1`
- `stream INTEGER NOT NULL DEFAULT 1`
- `background TEXT NOT NULL DEFAULT ''`（相对路径，空 = 没设）

schema v12（和 `shell_services` 同一版）。

**背景图不存 BLOB**：存路径，文件在 `files/backgrounds/`。理由和附件一样（D216）——
备份要能带上，库也不该被几 MB 的图撑大。
