## 0. 这一份管什么

四件事，共用一套文件列表与一套动作：

1. **文件预览**：点一个文件之后看什么（渲染 / 源码 / 详情）。
2. **对话内的「对话文件」面板**：附件 / 输出 / 工作区 三个页签。
3. **工作区独立页**：文件 / 工具 两个页签。
4. **终端**：从聊天页工具面板右边那颗按钮进。

不在这份里：MCP、技能管理、环境安装流程（那些各有自己的批次）。

## 1. 文件预览：类型决定页签

参考图里 html 是「渲染 / 源码」两个页签、默认渲染；代码是只有源码；APK 是「打开方式 / 分享 / 导出」。

**判定顺序就是这个顺序**（先判能不能渲染，再判能不能显示源码，最后才是详情）：

| 类型 | 判据 | 页签 | 默认 |
|---|---|---|---|
| HTML | 后缀 `.html` / `.htm` | 渲染 + 源码 | **渲染** |
| Markdown | 后缀 `.md` / `.markdown` | 渲染 + 源码 | **渲染** |
| 图片 | 后缀 `.png` `.jpg` `.jpeg` `.webp` `.gif` | 看图（缩放 / 适应宽度） | 看图 |
| 文本 / 代码 | 读出来是 UTF-8、无 NUL 字节 | 只有源码 | 源码 |
| 其它（APK / EXE / 压缩包 / 二进制） | 上面都不中 | 详情（大小 / 时间 / 路径 / 打开方式 / 分享 / 导出） | 详情 |

- **「渲染」页签只在真的有渲染器时才出现**。md 走已有的 `Markdown.kt`；html 走 `WebView`。
  `WebView` 的加载方式是 `loadDataWithBaseURL("file://<所在目录>/", html, "text/html", "utf-8", null)`——
  base URL 给目录，页面里的相对引用（`<img src="a.png">`）才找得到。
- **源码页不做完整语法高亮**。参考图里 `settle.rs` 是着色过的，但自写一个覆盖多语言的着色器是个坑，
  引依赖又违反项目习惯（D10 / zip 禁令同一个理由）。第一版做**行级最小着色**：
  注释（`//` `#` `--`）、字符串（`"` `'`）、数字，按后缀选一张关键字表（rust / kotlin / python / js / sh）。
  认不出语言的**不上色**，只给等宽 + 行号。这是"宁可少上，不要乱上"。
- **源码页带行号、可关折行**。行号与文本分开两栏（`Row` + 等宽），不靠字符串拼接——
  拼接版本在复制时会带上行号，而用户复制代码不想要行号。
- **大文件只读一页**：沿用 `read_file` 的 48 KB 硬上限（D343），到底了在底部写一行
  「已读 A–B 行，下面还有」。

### 顶栏

返回 + 文件名（单行省略）+ 右侧一组：下载 / 分享 / 用其他应用打开 / （html 才有）在浏览器里看。
**页签条在顶栏下面单独一行**，两个页签等宽，选中态用 `primaryContainer` 底 + `primary` 字。

## 2. 工作区：三个入口，一套组件

三处出现，形状不同、零件同一套（`FileRow` / `FileToolbar` / `FileActions`）：

### 2.1 对话内的「对话文件」面板（底部浮层）

标题「对话文件」，右上角关闭。下面一排三个页签：**附件 / 输出 / 工作区**。

**三个页签的数据源（这是最容易搞混的一处）**：

| 页签 | 来源 | 说明 |
|---|---|---|
| 附件 | 库里 `attachments` 表（`kind='file'`） | **用户发来的**原文件 |
| 输出 | 会话目录 `sessions/<id>/chat/` 里**没有**库记录的那些 | **AI 写的**；用户看不到就违反铁律② |
| 工作区 | 会话绑定的工作区根 | 与上面两个目录无关 |

前两个是同一个目录、两种归属：靠"库里有没有那条附件记录"分开。**不重叠、也不漏**——
每一份都能在界面上指出来（铁律②）。

**工作区页签的顶行**：作用域名（`Default`）+ 五个图标按钮，从左到右

1. **排序**（`⇅`）：名称 / 修改时间 / 大小，再点一次切升降。当前顺序写进状态，不写进库。
2. **显示隐藏文件**（`👁` / `👁⃠`）：**这条状态只存在本机客户端**（SharedPreferences），
   全局共用（所有工作区、所有会话同一个值），**不进备份**。用户原话：「如果带一个斜杠就是不显示」。
3. **新建文件 / 文件夹**：一个 `+`，点了开一个小面板选类型，再填名字。
4. **导入文件**：系统文件选择器（SAF），可多选，落到当前目录。
5. **导出文件**：把当前目录打个 tar.gz 到用户选的位置。

参考图里第 3、4 个按钮长得像"下载/上传"，我用 `+` 与导入/导出两个图标——
**`+` 只做一件事（新建）**，导入导出各一颗，不合成一个菜单。

**行**：图标（文件夹 / 文件）+ 名字（单行省略）+ 第二行（文件夹给时间，文件给大小 · 时间）+ 行尾 `⋯`。
`⋯` 打开底部小面板：改名 / 复制路径 / 分享 / 导出 / 删除（文件）；改名 / 复制路径 / 导出为压缩包 / 删除（目录）。
**删除走确认卡**（写清会没掉什么），跟删会话同一套。

### 2.2 工作区独立页（从设置进）

顶栏：返回 + 工作区名 + 「托管」徽标 + `⇅` / `+` / `⋯`。下面两个等宽页签：**文件 / 工具**。

- **文件**：与 2.1 的工作区页签同一套组件，只是没有"三个页签"这一层。
- **工具**：这个工作区的对话能用哪些工具，一行一个开关，改完即时保存。
  落到 `settings(workspace, <id>)` 的一份文档（D86 的形状），字段 `tools: {off: [名字]}`。
  **与助手/会话那两级开关取交集**：任何一级关掉就不声明。它是"再收一道"，不是"再放一道"。

### 2.3 设置 → 工具与工作区

三条入口（参考图最后五张）：

```text
工具与工作区
  本地工具        2/12         ›
  MCP 服务器      1/3          ›
  工作区          Default      ›   （列出全部工作区，点进 2.2）
  环境            就绪          ›   （状态 / 大小 / 安装于 / 架构）
  权限            请求批准      ›
```

**环境详情页**（图 10–11）分区固定：状态 / 大小 / 安装于 / 架构 → 浏览文件系统 / 挂载外部文件夹 →
环境变量 → 修复 / 检查更新 / 重置（重置是红色文字，走确认卡）→ 更换系统 / PRoot 配置。
底部一行灰字说明"重置环境不删工作区"。

## 3. 终端

### 3.1 三种来源与优先级

点那颗按钮**直接进默认终端**，长按弹出选择：

| 来源 | 名字 | 前置条件 |
|---|---|---|
| 容器 | `容器（Ubuntu 24.04）` | `EnvirSpec` 就绪 |
| 系统 | `系统 shell` | 恒可用 |
| 宿主 + 容器环境 | `宿主 shell（容器环境）` | 恒可用，但只是"看着像" |

**优先级：容器可用就用容器**，否则系统 shell。

### 3.2 第一版**不做 PTY**（这一条要写清代价）

真终端要 `forkpty` / `openpty`，Android 上没有公开 API，得自己写 native 或者塞一套 termios。
而项目现在跑命令的路子是 `Command::new("sh").arg("-c")` + 收 stdout/stderr。

**第一版做"命令回显式终端"**：一行一行发命令，输出追加到滚动区，提示符自己画。
- 能跑：`ls` `cat` `python x.py` `make` `npm install`、真正的构建与脚本。
- **不能跑**：`vim` `top` `htop` 这类全屏程序、需要交互输入的命令（`sudo` 要密码、`npm init` 的问答）、
  需要 TTY 才能输出的程序（很多程序在非 TTY 时会关掉颜色——这倒是好事）。
- 判据：`ls` 有输出；`vim` 明确报"这个终端不支持全屏程序"，**不要卡住**。

**升级路径**留好：`ShellSession` 这一层抽象出来，将来换 PTY 只换实现。

### 3.3 形状（参考图 9）

- 顶栏：返回 + 工作区名 + `⋯`（清屏 / 复制全部 / 切换终端 / 关闭）。
- 第二行：一颗胶囊状的当前来源徽标（`● Default`），右边一个 `+`（新建会话，第一版只有一个，`+` 灰着并写原因）。
- 主体：等宽文本，**自动滚到底**（用户往上翻的时候不抢）。
- 底部工具条：`Esc` `Tab` `Ctrl` `Alt` `←` `复制` `粘贴`。前四个是"下一键组合"的修饰键（按下后高亮，
  再按一个键就发 `\x1b` / `\t` / `Ctrl+C` / `Alt+X`）。复制/粘贴走系统剪贴板。
- 命令历史：上下键在本地历史里走（不入库、不进备份）。

### 3.4 终端里跑的东西也要记账

终端执行走**同一条** `shell` 路子（`track_changes` + `settle_changes`），所以终端里改了文件，
下一轮的变更卡片里能看到。**这一条不能漏**——否则用户从终端改的东西在界面上完全隐形（铁律②）。

### 3.5 「宿主 shell（容器环境）」的真实边界

用户说的是 termux 那种"系统 shell 但环境变量用容器的"。能做的是**数据目录与 PATH**：

```text
HOME=/workspace            （绑定的工作区，不是 rootfs 的 /root）
TMPDIR=<会话 tmp>
PATH=<rootfs>/usr/local/bin:<rootfs>/usr/bin:<rootfs>/bin:/system/bin
PREFIX=<rootfs>/usr
```

**不能给 `LD_LIBRARY_PATH` 指向 rootfs**：宿主的 `sh` 是 bionic 编的，链上 rootfs 里的 glibc 会直接
`CANNOT LINK EXECUTABLE`。所以这个模式**跑不了 rootfs 里的 ELF**，只能跑"已经装在宿主上、但按容器目录找数据"的东西。
界面上要如实写一句：「跑 rootfs 里的程序请用容器终端」。这是这一档的边界，不是 bug。

## 4. 状态归属（什么进备份，什么不进）

| 状态 | 存哪 | 进备份 |
|---|---|---|
| 显示隐藏文件 | SharedPreferences（全局一份） | **不进** |
| 排序方式 / 升降序 | 同上 | **不进** |
| 终端最后用的来源 | 同上（按工作区） | **不进** |
| 终端命令历史 | 同上（环形，最多 200 条） | **不进** |
| 工作区工具开关 | 库里 `settings(workspace,<id>)` | **进** |
| 文件本身 | 工作区目录 / 会话目录 | 进（备份按 D374 那套走） |

理由：前四样是"这台设备上怎么摆"的偏好，跟着库搬到另一台设备没有意义（那边屏幕不一样、终端也不一样）。
用户 2026-11-22 明确：显示隐藏文件那一条「只存储在本地客户端数据，也不走备份，全局共用的状态记忆」。

## 6. 分步（每步都能单独验）

1. **`FileKind` 判定 + 单测**（纯函数，本机 JUnit）。判据：18 个后缀各归对，未知后缀落到 `binary`。
2. **文件预览页**：源码页 + 行号 + 分页；md 走 `Markdown.kt`；html 走 `WebView`；二进制走详情。
   判据：四种类型各打开一次，都不白屏；大文件到底有"还有 N 行"；html 的相对引用能加载。
3. **工作区列表（只读）**：`workspace_list` + 五颗按钮里的排序与隐藏开关。判据：切隐藏开关，点开头的文件出现/消失；
   排序三种各切一次，顺序对得上。
4. **写操作**：新建 / 改名 / 删除 / 导入 / 导出。判据：建完列得出来；删完要确认、删完说剩几个；
   导出的 tar.gz 能解开。
5. **对话内三页签**：附件 / 输出 / 工作区。判据：发一个文件 → 附件里有；让模型写一个 → 输出里有；
   两份不重叠。
6. **工作区工具开关**（`settings(workspace,<id>)` + policy 取交集）。判据：关掉「运行命令」，
   这个工作区的会话就不再声明它。
7. **终端（系统 shell）**：回显式、命令历史、底部修饰键。判据：`ls` 有输出；`vim` 明确报不支持而不是卡住；
   `Ctrl+C` 能掐掉一条跑着的命令。
8. **终端（容器 / 宿主+容器环境）**：三档切换 + 长按选择。判据：三档各跑一次 `pwd`；
   容器档能跑 `apt` 之外的普通命令；宿主档跑 rootfs 里的 ELF 时给出那句"请用容器终端"。
9. **终端改文件进变更卡片**：判据：`echo x > a.txt` 之后，那一轮的变更卡片里有 `a.txt`。

前 4 步本机能验（第 2 步的 `WebView` 除外），5–9 要真机。

## 7. 未做 / 风险

- **不做 PTY**：全屏程序、交互式提示跑不了。要真终端得另开一批（native + termios）。
- **语法高亮只有行级最小集**：认不出的语言不上色。做完整高亮要引依赖或者写 parser，都不划算。
- **`WebView` 的加载面**：`file://` + 允许 JS。**要禁掉 `file://` 之外的跨域读**（`setAllowFileAccessFromFileURLs(false)`），
  否则一个模型写的 html 能读工作区里任意文件。这一条是安全边界，不是可选项。
- **导入/导出走 SAF**：`ActivityResultContracts` 的 `OpenMultipleDocuments` / `CreateDocument`。
  路径要经过 `content://` → 本地文件的复制，不能假设给的是真实路径。
- **工作区工具开关与现有 policy 的关系**要一次说清（取交集），否则会出现"两处都能关，谁说了算"。
- **终端历史里的敏感值**：用户可能把 token 打在命令行里，历史存在本机 prefs 里，**不进备份**（已在 §4 落）。

## 8. 看了 kelivo 的实现，抄什么 / 不抄什么

看了 `lib/features/workspace/widgets/preview/`（12 个文件）与 `terminal/`（4 个文件）。

**抄的（形状对，而且省钱）**：

- **类型分文件**：`html_file_preview` / `markdown_file_preview` / `code_file_preview` / `image_file_preview` /
  `binary_file_preview` / `csv_file_preview`，各管各的。我们的 `FileKind` 判定 → 分派，同构。
- **html 默认渲染**：`bool _showSource = false`，两个页签，默认在渲染。与用户要求一致。
- **代码页的行号是一列，不是拼进文本**：`code_file_preview` 里行号与正文是两段样式不同的文字并排，
  折行时还要按"一个源行占几个渲染行"补空行号。②我们的做法一致（`Row` 两栏），
  但**折行时补空行号这一步我不做**：关掉折行就没有这个问题，而开折行时行号错位比没有行号更糟。
- **分页读**：`paged_text_document` 分页取，不一次读完。我们的 `read_file` 48 KB 上限已经是这个意思。
- **`txt` 归到"代码"那一类**（只有源码页）：`kPreviewCodeExtensions` 里就有 `.txt` / `.log`。与用户要求一致。

**不抄的**：

- **`osc_1337.dart` 那类 OSC 序列解析**：它们要拦 PTY 字节流里的 `KelivoOpenURL`。我们不打算第一版上 PTY，
  也就没有字节流要拦。
- **每种后缀一套写死的图标颜色**（PDF 红 / doc 蓝 / 表格绿 / 音视频紫 / 代码靛…）：
  那是一张 12 个硬编码色值的表。我们的规矩是颜色只走主题角色（D120）。折中：
  **按大类着色**（代码 / 图片 / 压缩 / 可执行 / 文档 / 音视频），色值取 `primary` / `tertiary` / `error` /
  `onSurfaceVariant` 这几个已有的，不新增色板。
- **PTY**：`terminal_session_manager` 是真 PTY（`openTerminal` 注释里写了 `Opens a PTY`）。
  我们第一版不上，理由与代价见 §3.2。它的 `+` 多会话、`osc_1337` 都是建立在 PTY 之上的，
  **跟着一起不做**，而不是"先留着不接线"——留一个点了没反应的 `+` 比没有更糟。
